GOWINMALL — Architecture technique

1. Objectif

Construire une plateforme commerciale africaine moderne, sécurisée, modulaire et évolutive.

2. Architecture générale

GOWINMALL utilisera initialement une architecture modulaire.

Les différents modules partageront une infrastructure commune tout en conservant leurs responsabilités propres.

3. Technologies

- Next.js : application web.
- TypeScript : langage principal.
- Tailwind CSS : interface utilisateur.
- PostgreSQL : base de données.
- API sécurisée : communication entre les composants.
- React Native : future application mobile.
- GitHub : gestion du code source.

4. Organisation fonctionnelle

Comptes et utilisateurs

Inscription, connexion, profils et gestion des rôles.

Marketplace

Gestion des produits physiques et numériques.

Services

Publication et vente de prestations.

Tasks

Publication, attribution et validation des missions.

Affiliate

Suivi des liens et commissions d'affiliation.

Wallet

Historique des transactions et suivi des revenus.

Trust

Vérification des comptes, sécurité et gestion des litiges.

Admin

Gestion des utilisateurs, opérations, commissions et permissions.

5. Sécurité

- Authentification sécurisée.
- Contrôle des autorisations.
- Protection des données personnelles.
- Chiffrement des données sensibles.
- Journalisation des opérations administratives.
- Vérification humaine des dossiers sensibles.

6. Paiements

Les paiements seront intégrés avec des prestataires agréés et compatibles avec les pays ciblés.

Les méthodes envisagées comprennent :

- Mobile Money.
- Cartes bancaires.
- Autres moyens de paiement locaux.

GOWINMALL ne conservera pas directement les fonds des utilisateurs sans autorisation réglementaire appropriée.

7. Administration

GOWIN ADMIN sera un espace privé.

Le propriétaire disposera des permissions principales. Les employés auront uniquement les autorisations nécessaires à leurs fonctions.

8. Évolution

La plateforme commencera à Kinshasa avant son extension progressive aux autres marchés africains.

9. Indépendance

GOWINMALL possède sa propre architecture et ne dépend pas du projet Digitalstore.
